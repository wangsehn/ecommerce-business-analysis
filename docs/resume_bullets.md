# 简历项目描述（resume_bullets.md）

> 以下数字全部来自本项目真实运行结果，可直接写入简历。使用原则：做了什么 + 用了什么 + 分析了什么 + 得到什么结果。

## 项目概述（简历顶部一句话）

**《电商经营与用户价值数据分析》** —— 基于巴西 Olist 电商公开数据集（约 9.9 万订单、8 张业务表）的端到端商业分析作品集，覆盖数据清洗、MySQL 建模、商 SQL、四页 Dashboard 与业务洞察。

---

## 4 条可直接用的 Bullet

### Bullet 1（整体 + 建模 + SQL）
> 电商经营与用户价值分析｜Python / MySQL / SQL / Power BI
> 基于约 9.9 万笔真实订单、8 张业务表完成端到端经营分析，使用 Python 完成数据质量检查与清洗，并用 MySQL 构建多表分析模型（含外键约束与血缘关系）。

### Bullet 2（SQL 能力）
> 编写 30+ 条业务 SQL，使用 CTE、窗口函数（LAG、RANK、SUM/AVG OVER、PARTITION BY）完成经营趋势、Cohort 留存、复购、卖家分层及物流体验分析，并对结果用 Python 交叉核验。

### Bullet 3（业务发现）
> 识别 **复购率仅 3.0%**、**前 20% 卖家贡献约 82% GMV**、**物流超时订单评分下降 1.73 分**等关键经营问题，并形成"首单→二单转化、治理高延迟履约、平衡供给侧依赖"等对应的运营与履约优化建议。

### Bullet 4（可视化 + 指标体系）
> 搭建四主题经营 Dashboard，覆盖经营总览、用户价值、商品卖家及物流体验，并统一 GMV、AOV、复购率等核心指标口径（严格区分 customer_id 与 customer_unique_id、有效订单筛选、多商品/多支付去重），形成可交付的求职作品集体系。
