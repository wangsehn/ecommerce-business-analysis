# Power BI 目录说明

本作品集的 4 页可视化提供两种交付：

1. **可直接展示**：`../assets/dashboard/index.html`（真实数据渲染的 4 页交互式仪表盘）+ 各页图表 PNG。
2. **可复现的 .pbix**：`.pbix` 是 Power BI Desktop 的二进制格式，无法用脚本生成。
   请用 Power BI Desktop 按 `../docs/powerbi_setup.md` 的步骤（数据源接入 → DAX 度量 → 4 页布局）重建，约 1 小时。

重建完成后，把生成的 `ecommerce_analysis.pbix` 放入本目录，并导出 4 页截图为：
`../assets/dashboard/powerbi_page1..4.png`。
